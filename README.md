# Hooghly Service Hub — Version 2 Premium 3D

## Contents
- `index.html` — responsive local business directory and registration demo.
- `README.md` — setup and import notes.
- `data/sample-businesses.json` — sample category/listing data.

## Preview
Open `index.html` in a modern browser, or upload the project to a static web host.

## Admin import
If your hosting platform supports ZIP/static-site import, upload this ZIP and set the site root to this folder. If the platform expects a specific CMS/database import format, its name and required schema are needed before this package can be converted to that format.

## Important demo limitations
- Admin approvals and listings are stored in the current browser using localStorage.
- This is a front-end demo, not a secure multi-user admin system.
- For production use, connect a backend/database and protect the admin panel with authentication.
- Sample listings are placeholders and should be replaced with verified businesses.
